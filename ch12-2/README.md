## 실습과제 3

### 1. ①번 라인에서 `(int*)` 형변환을 사용한 이유
* 상수 `125`는 기본적으로 정수(int) 데이터 타입이다. 반면 포인터 변수 `ptr`은 주소값을 다루는 `int*` 타입이므로, 데이터 타입 불일치로 인한 컴파일 에러를 방지하고자 `(int*)`를 이용해 강제로 포인터형 변환을 진행한 것이다.

### 2. 프로그램 실행 중 오류가 발생하여 강제 종료되는 이유
* `125`번지 주소는 운영체제(OS)로부터 정식으로 할당받은 메모리 영역이 아니다. 이렇게 허가되지 않은 임의의 메모리 주소에 `*ptr = 10;`과 같이 접근하여 값을 수정하려고 하면, OS가 메모리 보호를 위해 접근 위반(Access Violation)을 발생시키고 프로세스를 즉시 강제 종료시킨다.
