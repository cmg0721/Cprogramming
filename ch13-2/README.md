## 실습과제 1: C언어 문자열 기본 개념

1. **C언어에서 문자를 메모리에 저장하는 방식**
   - C언어는 문자를 1바이트 크기의 정수 값으로 메모리에 저장하며, 이때 **아스키 코드(ASCII Code)** 표준을 사용합니다.

2. **널문자(`\0`)의 용도**
   - 문자열의 끝(종단)을 표시하여 어디까지가 문자열인지 알려주는 역할을 합니다.

3. **메모리에 저장된 문자열의 끝을 찾는 방법**
   - 배열/포인터의 시작부터 순차적으로 탐색하다가 널문자(`'\0'`)를 만나는 지점으로 끝을 파악합니다.

4. **문자열의 길이를 구하는 알고리즘**
   - 카운트 변수를 `0`으로 초기화한 뒤 널문자(`'\0'`)가 나올 때까지 순회하며 카운트를 1씩 증가시킵니다.
