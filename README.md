# 12장 포인터의 이해 - 실습과제

## 1. 이론 설명 문제 (실습과제 1, 2, 3)

### [실습과제 1]
1. **16MB 메모리의 주소 범위**: 0 ~ 16,777,215 (0 ~ 16 * 2^20 - 1)
2. **변수의 주소**: 변수가 메모리에 할당될 때 사용하는 공간의 시작 번지(가장 작은 주소).
3. **변수 주소의 자료형**: (가리키는 변수의 자료형)* (예: int*, char*)
4. **포인터란**: 메모리의 주소를 저장하기 위한 전용 변수.
5. **포인터의 자료형**: 자료형* (예: int*, double*)
6. **int형 변수에 주소 저장 시**: 주소 체계 불일치(64비트 환경 데이터 손실 발생 가능), 포인터 연산 사용 불가, 컴파일 경고/오류 발생.

### [실습과제 2] (`double * pt;`)
1. **pt가 가리키는 데이터의 자료형**: `double`
2. **pt에 저장될 주소의 자료형**: `double*`
3. **pt의 자료형**: `double*`
4. **double의 의미**: 포인터 pt가 가리키는 메모리 공간에 저장된 데이터의 자료형이 double(8바이트 실수)임을 의미.
5. **메모리 크기**: 32비트(x86) 시스템에서는 4바이트, 64비트(x64) 시스템에서는 8바이트.

### [실습과제 3]
| 수식 | 결과값 | 결과값의 자료형 |
| :--- | :--- | :--- |
| `&ch` | 100 | `char*` |
| `&in` | 101 | `int*` |
| `&db` | 105 | `double*` |

## 2. 실습과제 4 - 소스코드 및 라인별 설명

```c
#define _CRT_SECURE_NO_WARNINGS // scanf 보안 오류 방지
#pragma warning(disable:6031)   // 리턴값 관련 경고 방지
#include <stdio.h>

// ******************************************************
// 제목: 12장 포인터의 이해 실습과제 4
// 날짜: 2026년 9월 5일
// 작성자 : 학번 채민기
// ******************************************************

int main(void)
{
    char a = 'A';             // char형 변수 a 선언 및 'A'로 초기화
    int b = 36;               // int형 변수 b 선언 및 36으로 초기화
    double c = 3.141592;      // double형 변수 c 선언 및 3.141592로 초기화

    // 주소 연산자(&)를 이용해 각 변수의 주소를 구하고 %p 서식 지정자로 출력
    printf("char형 변수 a의 주소 : %p\n", (void*)&a);
    printf("int형 변수 b의 주소 : %p\n", (void*)&b);
    printf("double형 변수 c의 주소 : %p\n", (void*)&c);

    return 0;                 // 프로그램 정상 종료
}
