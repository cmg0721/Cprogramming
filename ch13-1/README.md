## 1. 실습과제 1: 포인터와 배열 개념 정리

### Q1. 배열명의 의미를 설명하라.
배열명은 배열의 첫 번째 요소의 주소를 나타내는 **주소 상수(포인터 상수)**입니다. 변수가 아닌 상수이므로 대입 연산자를 통해 주소 값을 변경할 수 없습니다.

### Q2. 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.
* **배열 요소의 값:** `arr[i]` <-> `*(arr + i)`
* **배열 요소의 주소:** `&arr[i]` <-> `arr + i`

### Q3. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있는 이유와 방법
배열의 모든 요소는 메모리에 연속적으로 할당됩니다. 따라서 `(첫 번째 요소 주소) + (인덱스 * 요소의 자료형 크기)` 공식을 이용하여 모든 요소의 주소를 계산할 수 있습니다.

### Q4. 배열의 첫 번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있는 방법
배열 요소의 주소 `arr + i`에 간접참조 연산자 `*`를 사용하여 `*(arr + i)` 형태로 접근하면 해당 메모리에 저장된 값을 가져올 수 있습니다.

### Q5. 포인터에 대해 가능한 연산의 종류와 의미
* **가능한 연산:** 간접참조(`*`), 정수 덧셈(`+`), 정수 뺄셈(`-`), 증감 연산자(`++`, `--`)
* **의미:** 포인터 연산 시 주소 값의 변화는 단순 정수 증가가 아니라 `포인터가 가리키는 자료형의 크기 * n` 만큼 이동합니다.
* **포인터 자료형 표현:** 포인터의 자료형은 `(자료형)*` 형식인 `char*`, `int*`, `double*` 등으로 표현합니다.

### Q6. 포인터 연산을 기존의 산술연산과 다르게 정의한 이유
포인터 연산의 목적은 메모리상에서 연속된 데이터 요소(배열 원소) 간 이동입니다. 자료형마다 메모리 차지 크기(`int`: 4바이트, `double`: 8바이트)가 다르므로, 해당 자료형 크기 단위로 주소가 이동해야 올바른 원소에 정확히 접근할 수 있기 때문입니다.

## 3. 실습과제 3: 증감연산자 및 포인터 상수 문제 해결

### 개념 설명
1. **`a++`와 `++a`의 차이:**
   * `a++` (후위 증감): 현재 수식에서 기존 `a` 값을 먼저 사용한 뒤 1 증가시킵니다.
   * `++a` (전위 증감): `a` 값을 먼저 1 증가시킨 뒤 수식 연산을 진행합니다.
2. **코드의 문제점 및 해결 방안:**
   * 배열명 `a`는 포인터 상수로 값을 변경할 수 없으므로 `a++` 시 컴파일 에러가 발생합니다.
   * 주소 변경이 가능한 포인터 변수 `ptr`(`int* ptr = a;`)을 별도로 선언한 후 `*ptr++` 형태로 접근하여 해결합니다.
