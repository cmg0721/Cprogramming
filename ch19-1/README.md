# 19장 및 20장 실습과제 및 도전문제 결과 보고서

## 실습과제 1
1. **함수 선언, 호출, 정의를 각각 설명하라**
   - 선언: 컴파일러에게 함수의 이름, 반환형, 매개변수 타입을 사전에 알리는 작업입니다.
   - 호출: 프로그램 수행 중 함수의 이름을 지정하여 실행을 요구하고 인자를 전달하는 작업입니다.
   - 정의: 함수의 실행 코드 몸체를 온전하게 작성하여 실제 기능을 구현하는 작업입니다.
2. **함수의 자료형은?**
   - 반환형과 매개변수의 자료형 및 개수로 정의됩니다.
3. **함수명의 자료형은?**
   - 함수의 주소를 의미하므로 (자료형)* 형태를 가지며, 표현하면 반환형 (*)(매개변수자료형1, 매개변수자료형2, ...) 입니다.
4. **void 포인터의 용도는?**
   - 자료형이 지정되지 않은 주소 저장 변수로서 모든 타입의 변수 주소 및 함수 주소를 담을 수 있습니다.
5. **void 포인터에 간접참조 연산을 적용할 때 주의할 점은?**
   - 주소의 크기와 단위를 알지 못하므로 반드시 사용할 자료형으로 명시적 강제 형변환을 한 뒤에 간접참조 연산(*)을 적용해야 합니다.
6. **강제형변환과 자동형변환을 설명하시오**
   - 자동형변환: 컴파일러에 의해 데이터의 손실이 없거나 표현 범위가 넓은 자료형으로 자동 처리되는 변환입니다.
   - 강제형변환: 프로그래머가 필요에 의해 캐스팅 연산자를 사용하여 명시적으로 자료형을 변경하는 변환입니다.
