##  실습과제 1: 이중 포인터 메모리 및 수식 분석

### 변수 메모리 할당 가정 조건
* `double num = 6.28;` (주소: 100)
* `double* ptr = &num;` (주소: 300)
* `double** dptr = &ptr;` (주소: 500)

### 분석 결과 표

| 수식 | 결과값 | 결과값의 자료형 | 설명 |
| :--- | :--- | :--- | :--- |
| **`ptr`** | 100 | `double*` | 변수 `num`의 메모리 주소값입니다. |
| **`dptr`** | 300 | `double**` | 포인터 변수 `ptr`의 메모리 주소값입니다. |
| **`&ptr`** | 300 | `double**` | 싱글 포인터 `ptr` 변수 자체의 주소입니다. |
| **`&dptr`** | 500 | `double***` | 이중 포인터 `dptr` 변수 자체의 주소입니다. |
| **`*ptr`** | 6.28 | `double` | 포인터 `ptr`이 가리키는 100번지의 실제 데이터 값입니다. |
| **`*dptr`** | 100 | `double*` | 이중 포인터 `dptr`이 참조하는 `ptr` 안의 값(주소)입니다. |
| **`**dptr`** | 6.28 | `double` | 두 번의 연속 역참조를 통해 원본 변수 `num`에 접근한 값입니다. |

## 실습과제 4: 교재 368페이지 문제 17-1 코드 라인별 설명

### 1. 주요 핵심 구문 해설
* **`void MaxAndMin(int* arr, int size, int** pMax, int** pMin)`**
  * `main` 함수 외부에서 선언된 싱글 포인터 변수의 주소 자체를 변경해야 하므로, 주소에 의한 호출을 만족하기 위해 매개변수를 이중 포인터 자료형(`int**`)으로 정의합니다.
* **`max = &arr[i]; / min = &arr[i];`**
  * 배열 전체 요소를 비교 검사하며 최댓값 혹은 최솟값을 가진 배열 원소를 발견할 때마다 값이 아닌 원소의 주소값 자체(`&`)를 임시 포인터 주소 변수에 백업합니다.
* **`*pMax = max; / *pMin = min;`**
  * 역참조 연산자(`*`)를 적용하여 매개변수가 가리키는 `main` 함수 내부의 싱글 포인터 원본 변수 공간에 최종 연산된 주소값을 직접 대입합니다.
* **`MaxAndMin(arr, 5, &maxPtr, &minPtr);`**
  * `main` 내부의 싱글 포인터 변수의 메모리 주소값(`&`)을 인자로 명시하여 함수를 호출합니다.
