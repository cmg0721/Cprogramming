## 실습과제 1: 주소에 의한 호출 및 const 변수 이해

### 1. 주소에 의한 호출(Call by Reference)을 사용해야 하는 3가지 경우
* **지역 변수 값 변경:** 다른 함수 내부에서 선언된 지역 변수의 원본 값을 직접 수정하고 싶을 때 사용합니다.
* **배열의 인자 전달:** C언어는 배열 전체를 값으로 복사해 넘길 수 없으므로, 대용량 배열을 다룰 때 메모리 절약과 성능 개선을 위해 배열의 시작 주소를 전달합니다.
* **다중 값 반환:** C언어 함수는 오직 1개의 반환값만 가질 수 있으므로, 2개 이상의 결과를 돌려받아야 할 때 포인터 매개변수를 이용해 호출한 곳의 변수를 직접 업데이트합니다.

### 2. 최대값 구하는 알고리즘 설명
* 기준이 될 임시 최대값 변수를 생성하고, 배열의 첫 번째 원소값으로 초기화합니다.
* 반복문을 사용해 배열의 두 번째 원소부터 마지막 원소까지 순차적으로 접근합니다.
* 매 단계마다 현재 원소의 값과 임시 최대값을 비교하여, 더 큰 값이 나타나면 임시 최대값 변수의 값을 해당 원소의 값으로 완전히 갱신합니다. 전체 배열을 모두 순회하면 최종 최대값이 결정됩니다.

### 3. const 선언을 사용하는 이유
* 함수 내부에서 포인터 매개변수가 가리키는 원본 배열의 데이터를 실수로 조작하거나 훼손하는 것을 문법적으로 완벽히 차단(컴파일 에러 발생)하여 코드의 안전성을 보장합니다.
* 해당 함수를 사용하는 호출자에게 "이 함수는 입력 데이터를 오직 읽기(참조) 전용으로만 다룬다"라는 명확한 신뢰성을 제공하기 위해 사용합니다.
